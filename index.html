Font Styling Varients and Inline Styling

  • Cool Website — px is an absolute size used when you need a fixed size that never changes, like a border or icon
  • Cool Website — pt is an absolute size (1/72 of an inch) used for print layouts like a resume where you need precise physical sizing
  • Cool Website - em is a relative size based on the parent element's font size. It's useful for components that should scale with their container, like button text that should grow if the surrounding text grows.
  • Cool Website - vh is a relative size based on the viewport height (2% of the browsers height in this example). Useful for text that should scale with the screen size, like a title on a landing page where you want the text to always be proportional to how tall the browser window is.
  • Cool Website - rem is a relative unit based on the root html font size. Useful when you want all text on the page to scale consistently when you change one base font size.
  • Cool Website - % is a relative unit based on the parent element's font size. Useful when you want text inside a component to be proportionally larger than its container, like a heading that should always be 150% the size of the surrounding text.
